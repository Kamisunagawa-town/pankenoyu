# 上砂川岳温泉 パンケの湯 臨時ホームページ

上砂川岳温泉「パンケの湯」の臨時（暫定）ホームページです。
本サイトは GitHub Pages で公開しています。

公開URL: https://kamisunagawa-town.github.io/pankenoyu/index.html

---

## このサイトについて

本サイトは、通常運用していたホームページのサーバー不具合に伴い、
応急的な情報発信のために作成した臨時サイトです。
施設のご案内・お知らせ・宿泊プランなどを掲載しています。

---

## ファイル構成

- index.html … トップページ（施設紹介・お風呂・料金・アクセス）
- plan.html … 宿泊プラン・ご予約ページ
- sitemap.xml … 検索エンジン向けサイトマップ
- robots.txt … クローラー向け設定
- README.md … このファイル
- css/style.css … 全ページ共通のスタイル
- js/news.js … お知らせを読み込む処理
- js/plan.js … 宿泊プランを読み込む処理
- data/news.json … お知らせデータ
- data/plan.json … 宿泊プランデータ
- images/ … 画像ファイル一式（hero.jpg, spa-inside.jpg, sauna.jpg, dinner.jpg, breakfast.jpg, room-japanese.jpg, room-western.jpg など）

※ファイルの実際の配置に合わせて、パスは適宜修正してください。

## 更新方法

### お知らせを更新する

data/news.json を編集します。記載例:

    [
      {
        "date": "2026.07.30",
        "text": "お知らせの本文をここに入力します。"
      },
      {
        "date": "2026.07.28",
        "text": "2件目のお知らせ。"
      }
    ]

注意点:

- 各項目は波かっこで囲み、項目間はカンマで区切る
- 最後の項目の後ろにはカンマを付けない（付けると表示されなくなります）
- 新しいお知らせは上に追加する

### 宿泊プランを更新する

data/plan.json を編集します（記載ルールは news.json と同様）。

### 画像を差し替える

images/ フォルダ内の同名ファイルを上書きします。
※ファイル名はすべて小文字で統一してください。

## 公開の仕組み

- main ブランチに push すると、GitHub Pages が自動でサイトを再構築・公開します。
- 反映まで通常 1〜2 分ほどかかります。
- 変更が見えないときは、ブラウザで Ctrl + F5（強制リロード）を試してください。

---

## 検索エンジン対応

- sitemap.xml … サイト構成を検索エンジンに伝えるファイル
- robots.txt … クローラーの巡回ルールとサイトマップの場所を記載
- Google Search Console にサイトマップを登録済み（または登録予定）
